# Ledgora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Comptroller / treasurer executive

- As a comptroller, I want a single digital strategy with an accountable owner and milestone status, so that we join the 90% maturing cohort pattern rather than the 30% early-stage pattern.
- As a treasurer, I want cash and cost-management initiatives ranked against fraud and audit use cases, so that competing priorities do not starve the highest-yield work.

### Audit manager

- As an audit manager, I want continuous-audit exceptions with materiality context, so that we spend scarce hours on high-risk items instead of only periodic samples.
- As an audit manager, I want independence checks when we rely on auditee-configured analytics, so that our opinion remains defensible.

### Revenue integrity analyst

- As a revenue analyst, I want prioritized fraud leads from returns and payments, so that we keep pace with fraudsters the way New York’s cited program intends.
- As a revenue analyst, I want adjudication outcomes to retrain risk scoring under privacy controls, so that detection improves without unlawful secondary use.

### Procurement officer

- As a procurement officer, I want modular digital SOW templates and T&C playbooks, so that we can buy agile delivery without violating purchasing statutes.
- As a procurement officer, I want vendor performance scored on modular outcomes, so that low satisfaction with tech vendors has a remedy path.

### Workforce / strategy lead

- As a workforce lead, I want skills-gap plans with organisational support flags, so that “lack of skills” is not a permanent excuse.
- As a strategy lead, I want security and privacy gates on each use case, so that the top barriers are managed inside the portfolio.
- As an audit manager (exception), I want to halt an automated recovery when independence or materiality rules are breached, so that speed does not corrupt the audit.
